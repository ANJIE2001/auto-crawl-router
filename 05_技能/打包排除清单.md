# 打包排除清单

> 要把这个项目**发给别人**（压缩包 / 拷 U 盘 / 上云盘）之前，照这份对一遍。
> 只给自己换电脑的话，看最后一节。

---

## 一句话

**能发的是「代码 + 文档」，不能发的是「钥匙 + 数据 + 私人记录」。**

| 类别 | 具体 | 为什么不能发 |
|---|---|---|
| 🔑 **钥匙** | `.env` | 里面有得到大脑的 API Key，**全权限**，能读到你账号里所有东西 |
| 🔑 **钥匙** | `01_采集/*/config.local.json` | 老位置，真值已搬走，但**保险起见一律排除** |
| 📦 **数据** | `02_储存/` | 抓回来的原始数据，体积大 |
| 📦 **数据** | `04_产出/` | 成品和封面，体积大 |
| 🔒 **私人记录** | `.workbuddy/memory/` | 私人笔记 ID、邮箱、积分余额 |
| 🗑️ **垃圾** | `__pycache__/`、`*.pyc`、`.tmp_*` | 没用 |

## 怎么执行

### 打个压缩包发给别人（PowerShell）

```powershell
# 在项目根目录跑。只装代码 + 文档，钥匙和数据都不进包
$out = "..\自动抓取内容路由_分发版.zip"
$exclude = @(".env", "02_储存", "04_产出", ".git", ".workbuddy\memory",
             "config.local.json", "__pycache__")
Get-ChildItem -Recurse -File | Where-Object {
    $p = $_.FullName
    -not ($exclude | Where-Object { $p -like "*\$_\*" -or $_.FullName -eq $p -or $p -like "*\$_" })
} | Compress-Archive -DestinationPath $out -Force
```

> 打包前一定盯一眼：**包里不能有 `.env`**。

### 发之前自检

```bash
# 1. 密钥扫描（八项自检里的第一项就是它）
python 05_技能/selfcheck.py --quiet

# 2. 手工确认 .env 和 config.local.json 没被带进去
#    解压到临时目录，翻一遍有没有这两个文件名
```

**看到「错误 0」才是干净的。**

## 关于「安装包」

如果你说的是**发给学员的专家包**（`niki-clone.zip` 那种，装进 WorkBuddy 的）：

那个包里**本来就没有这个项目文件夹** —— 它是专家人格 + skills，不带数据也不带凭证。
所以得到大脑的 key 不会进去。**但仍然不能让 key 出现在任何你手动打包的东西里。**

两种包都按上面这份清单排 —— 排除规则写死，不靠记性。

---

## 只给自己换电脑

那就不用排得这么狠，但**钥匙仍然不能进 git**：

- 直接整个文件夹拷过去（含 `02_储存` / `04_产出`，省得重抓）
- `.env` 要一起拷 —— **它是钥匙**，换了机器没有它就跑不起来
- `~/.lingzao/`（灵造 CLI 和凭证）在项目外面，**单独拷或者重新装**
  装完跑 `python 05_技能/prereq_check.py` 复查

---

## 为什么不用 `.gitignore`

`.gitignore` 只管 **git 仓库**，管不了你手动拖进压缩包的文件。
`.env` 已经写进 `.gitignore` 了（不会被误提交），
**但压缩包是另一回事 —— 这份清单补的就是这个缺口。**
