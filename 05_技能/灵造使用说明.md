# 灵造使用说明

灵造是一个装在 Agent 里的自媒体研究工具。
你给它一个关键词、一个账号或一条笔记，它去公开平台把数据查回来，再给你判断。

这份说明只讲三件事：**装什么、怎么配、怎么用。**

---

## 一、你手上应该有三样东西

| 拿到的东西 | 是什么 |
|---|---|
| **灵造 API Key** | 一串 `lgz_` 开头的字符。查数据要用它 |
| **灵造 Skill** | 提示词包。装进 Agent 就能用 |
| **这份说明** | 你现在看的 |

少哪样，找发给你的人要。

---

## 二、先分清：哪些免费，哪些要 Key

**装好就能用（不花钱）：**

- 判断账号定位、赛道难度、内容主线
- 起小红书标题、封面方向、发布关键词
- 改草稿、拆解你给的材料、发布前检查
- 根据你提供的数据做复盘
- 把一份长分析整理成文档

**必须配 Key 才能用（扣积分）：**

- 搜小红书 / 抖音 / TikTok / Instagram / YouTube / 视频号的公开内容和创作者
- 看某个博主的主页、近期作品、深度分析
- 打开单条内容详情，读评论区
- 提取短视频口播文案、字幕、逐字稿
- 看公众号公开文章和文章数据
- 生成封面、配图

一句话：**做判断不用 Key，查数据要 Key。**

---

## 三、开始前你要准备

| 准备什么 | 为什么 |
|---|---|
| Agent 环境 | WorkBuddy / OpenClaw / Codex，有其一就行 |
| Node.js | 装 Skill 用到 `npx` |
| Python 3.8 或更高 | 跑灵造的命令行工具 |
| 灵造 API Key | 在 <https://lingzao.atian.vip> 开通在线服务后获取 |

---

## 四、装上，三步

### 第 1 步 · 装灵造 Skill

```bash
npx skills add https://assets-tian.midao.site/skills/lingzao --skill lingzao -g --copy
```

### 第 2 步 · 配 API Key

找到灵造 Skill 的目录 —— 就是那个含 `SKILL.md` 的文件夹。在它下面跑：

```bash
bash "<灵造Skill目录>/scripts/setup.sh" --base-url "https://lingzao.atian.vip"
```

跑到出现 `Lingzao API Key:` 的时候，把 Key 粘进去，回车。

也可以一条命令带上 Key，省掉那一步：

```bash
bash "<灵造Skill目录>/scripts/setup.sh" --api-key "lgz_你的Key" --base-url "https://lingzao.atian.vip"
```

**`--base-url` 一定要带。** 不带的话它会指向本地地址，连不上。

配完长这样：Key 存在 `~/.lingzao/config.json`，文件权限 0600，只在本机，不会外传。

常用维护命令：

```bash
# 看当前配了什么（Key 会打码）
python "<灵造Skill目录>/scripts/configure.py" --show

# 换 Key：把第 2 步的命令重跑一遍
# 清空配置
python "<灵造Skill目录>/scripts/configure.py" --reset
```

### 第 3 步 · 自检

```bash
~/.lingzao/bin/lingzao doctor
```

它会回答三个问题：命令找到没、连得通没、账号是谁。正常就装好了。

> **Windows 用户**：命令是 `%USERPROFILE%\.lingzao\bin\lingzao.cmd doctor`。
> 上面那些 `bash` 开头的命令，在 Git Bash 里跑。

## 五、怎么用：直接说人话

不用背命令。装好之后，把任务说给 Agent 就行。

下面这些可以直接抄：

| 你想干什么 | 就这么说 |
|---|---|
| 找内容方向 | 用灵造围绕「AI 写作」做小红书选题，给我 10 个能发的方向 |
| 找对标账号 | 帮我找 3 个母婴赛道值得学的对标账号，说明每个适合学什么 |
| 拆一条内容 | 分析这条笔记为什么有效，拆成标题、封面、结构、评论需求和可复用模板 |
| 改标题和封面 | 基于我这个草稿，给我 3 个最强标题和 5 个小红书封面方向 |
| 发布前检查 | 发布前帮我检查标题、封面、前 3 行、关键词和用户点击理由 |
| 发布后复盘 | 根据这条内容的数据和评论，帮我判断下次要调整什么 |
| 做每周内容包 | 把我这一周的素材整理成 5 个母题，再分发成小红书、公众号、播客和短口播 |
| 校准公众号对标 | 我发几篇喜欢的公众号文章和一篇自己的内容，先判断适不适合我学，不适合再补找对标，然后帮我写成自己的文章 |
| 做图片素材 | 先帮我设计封面方向，确认后再生成 |

**写提示词的诀窍：说清「平台 + 数量 + 你要什么」。**
"小红书，找 3 个母婴赛道的对标账号" 比 "帮我找对标账号" 好用得多。

## 六、扣费规则 ★ 动手前先看这节

灵造按**实际查看了什么**算积分，不按你发了几条消息算。
一句"帮我做全账号诊断"，可能触发几十次查询。**先说清楚再动手，是省钱的关键。**

| 你在做什么 | 花多少 |
|---|---|
| 普通搜索 / 搜创作者 / 主页资料 / 主页近期作品 / 单条详情 | **20 积分/次** |
| 看评论 | **20 积分/页** |
| 主页深度解析 | 1–20 条作品 **50 积分**；21–40 条 **100 积分** |
| 提取短视频文案 | 按视频真实时长 **10 积分/分钟**（最低 1 分钟）；开始前余额要有 50 积分 |

**三个最容易搞错的点：**

1. **一次搜索能返回很多条，不是按条数扣。** 一次普通搜索 20 积分，返回几条都算这一次。
2. **但接着点开每一条，都会另外算。** 搜完再逐条打开详情、看评论、拉字幕，全是新增消耗。
3. **关键词报告是累加的。** 主词 + 5 个相关词 = 6 次搜索，大约 120 积分。

### 两档搜索，动手前先选

- **基础搜索** —— 看一个已知的账号、一条笔记，或一小批。看标题、封面、互动数据、链接。适合先快速判断。
- **深度搜索** —— 多个关键词、多个账号，还要看完整正文、字幕、逐字稿。适合爆款深拆、账号诊断、找对标。

灵造会在开始前提醒你选哪档，**不会自己扩大范围**。

### 额度护栏

- 第一轮默认：最多 5 次查询，或约 100 积分。
- 可能超过 100 积分：先给你看计划、预计花费和停止点，等你点头。
- 可能超过 200 积分：必须你明确确认才开工。

觉得不对，随时喊停。

## 七、你能拿到什么

灵造的输出默认是 Markdown，在对话里直接读。

- **判断和建议** —— 方向、标题、封面思路、下一步动作
- **数据** —— 搜到的内容、账号、互动指标
- **逐字稿** —— 视频口播文案的全文
- **图片** —— 生成的封面、配图，存到你指定的路径
- **文档** —— 可整理成 Markdown / Word / 网页版

如果 Agent 环境接了知识库（ima / Obsidian / 飞书），灵造会**先问你要不要同步**，不会自己往里存。

## 八、常见问题

**没有 Key 能用吗？**
能。选题判断、标题封面、账号诊断、改稿、发布检查、复盘都不用 Key。要查公开数据的时候再配。

**为什么装的时候提示需要 API Key？**
装是免费的。灵造里面有在线查询和图片生成能力，这两类才需要 Key。

**换电脑了怎么办？**
在新电脑上把第四节走一遍。同一个 Key 可以多台机器用。

**查询失败了怎么办？**
先跑 `lingzao doctor` 看连接。图片生成和文案提取是异步任务，要等一会儿。
提示"灵造服务暂时不可用"就稍后重试；如果给了 `error_id`，记下来方便排查。

**能查别人账号的后台数据吗？**
不能。只查公开可见的内容。

**它会保证我的内容爆吗？**
不会。灵造做的是公开内容研究和运营判断，帮你做决策和复盘，不保证结果，也不能用来搬运别人的内容。

---

## 九、它不做什么

- 不保证爆款、涨粉、变现
- 不做全平台监控
- 不做批量数据导出
- 不复制他人内容

判断权始终在你手上。灵造给的是证据和方向，不是替你拍板。
