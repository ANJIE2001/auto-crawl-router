# 统一字段 · 列名词表

**这份是约定，不是代码。**

两个源（灵造、得到大脑）**各自实现自己的字段定义** —— `01_lingzao/record.py` 和
`02_getnote/record.py`，代码不共用、允许冗余（删一个目录不影响另一个）。

但**中文列名必须用同一套词**。因为用户定的原则是：

> 「代码层要分开……输出层不分开无所谓，输出层是给人读的。」

列名一致，两张表在 Excel 里才能对齐合并，人读的时候也不用切换脑子。

## ★ 三态铁律：`未知` 不是 `0`

第 13-19 列（时长 / 点赞 / 收藏 / 评论 / 分享 / 互动总量 / 收藏点赞比）
在得到大脑那边**全是「未知」**。
（第 29 列「封面URL」**不属于**这一类 —— 得到大脑走 HTTP 详情，拿得到。）

**别把「未知」当 0 去加总。** 0 是「确实没互动」，未知是「这个来源压根没有这个字段」。
混在一起会让人误判。

导出逻辑见各自 `record.py` 的 `_num()` / `_tri()`。

## 改列的规矩

**加列**（新来源带来新字段）：两边 `record.py` 的 `to_row()` 都加，位置保持一致；
列宽在各自 `export.py` 的 `COL_WIDTHS` 里补。

**改列名**：两边一起改，改完**两边的历史表都要重跑** —— 否则同一个列名在两批表里
指的不是一回事。

**删列**：先想清楚历史表怎么办。宁可留空列（显示「未知」），也别删了让人对不上。
